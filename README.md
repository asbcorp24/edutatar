# EduTatar Publisher

Windows-приложение для автоматизации работы с `edu.tatar.ru` через настоящий Chromium (Playwright).

## Что уже есть

- запуск Chromium через Playwright;
- постоянный профиль браузера в `data/browser_profile`;
- вход через поля `main_login2` / `main_password2`;
- ожидание штатной цепочки редиректов `/logon -> /start/logon-process -> /user/anketa`;
- проверка активной авторизации;
- GUI на PySide6;
- пароль не хранится в репозитории и не пишется в лог.

## Установка

Требуется Python 3.11+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
playwright install chromium
python app.py
```

## Первый запуск

1. Введите логин и пароль от `edu.tatar.ru`.
2. Нажмите **Войти**.
3. После успешного входа Chromium использует постоянный профиль, поэтому последующие запуски смогут использовать сохранённую сессию.
4. Кнопка **Проверить сессию** открывает `/user/anketa` и проверяет, не перебросил ли сайт обратно на страницу входа.

## Безопасность

- Не добавляйте реальные пароли, cookies `DNSID` / `HLP` и каталог `data/` в Git.
- Если сессионные cookies были опубликованы где-либо, завершите сессию на сайте.
- CAPTCHA/2FA приложение не обходит; такие проверки выполняются пользователем в открытом браузере.
